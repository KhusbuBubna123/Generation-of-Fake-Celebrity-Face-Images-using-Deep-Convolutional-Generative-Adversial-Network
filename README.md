# Hollywood Celebrity Fake Face Images Generation Using Deep Convolutional Generative Adversial Network (DCGAN).
In this project, Deep Convolutional Generative Adversial Network was trained on Celebrity Dataset.(source:Kaggle). The
network was trained for 100 epochs. Then few new Fake Celebrity Images were generated using Generator Model of DCGAN. 
Also Discriminator Model was used to discriminate Real vs Fake Celebrity Face Images as generated by the generator model 
of DCGAN. Then Real Image, Fake Image and Discriminator Accuracy was calculated. Then Generator Loss and Discriminator Loss
was calculated and plotted.
## GAN Architecture
A Generative Adversarial Network (GAN) is a machine learning framework where two neural networks compete against each other to create realistic synthetic data.
<img width="850" height="371" alt="GAN_architecture2" src="https://github.com/user-attachments/assets/b64a4b95-b7ac-4989-8698-8dbc5b3f09f9" />
**The Generator:** This network takes random noise as input and transforms it into new, synthetic data (like an image or audio). Its goal is to fool the discriminator. 
**The Discriminator:** This network acts as a binary classifier. It receives both real data from a training set and fake data from the generator. Its job is to tell 
which data is real and which is fake. 
The Adversarial Game: The two models improve together through competition. As the generator gets better at making fakes, the discriminator gets better at 
spotting them.  \

A Deep Convolutional Generative Adversarial Network (DCGAN) is a powerful extension of standard GANs that replaces \
fully connected layers with convolutional and transposed convolutional layers to stabilize training and generate \
high-resolution images. \
